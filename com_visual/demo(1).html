Librería UIKit — pruebas de Modal, Tooltip y Carrusel

1 Modal — desde JavaScript

Modal — solo con HTML (sin JS propio)

<button
  data-ui-modal
  data-title="Hola desde HTML"
  data-content="Contenido del modal">
  Abrir modal
</button>

2) Tooltip — solo con HTML

<button
  data-ui-tooltip
  data-text="¡Este es un tooltip!"
  data-position="top">
  Pasa el mouse aquí
</button>

3) Carrusel — desde JavaScript

UIKit.carousel('#carrusel-demo', {
  images: ['img1.jpg', 'img2.jpg', 'img3.jpg'],
  interval: 3000
});
